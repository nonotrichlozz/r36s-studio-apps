# r36s-studio-apps

Copies d'applications tierces que [R36S Studio](https://github.com/nonotrichlozz/r36s-studio) installe sur une console Android branchée en USB (outil « Console Android »).

Chaque application reste la propriété de son auteur et garde sa propre licence. Ce dépôt ne contient **aucun jeu, aucune ROM, aucun BIOS**.

Les fichiers sont publiés dans les [Releases](https://github.com/nonotrichlozz/r36s-studio-apps/releases), jamais dans le code du dépôt. L'empreinte SHA-256 de chaque fichier est fixée dans la fiche correspondante du [catalogue](https://github.com/nonotrichlozz/r36s-studio-catalogue) : R36S Studio refuse un fichier qui ne correspond pas.

## R36S Studio pour Android

L'application R36S Studio pour téléphone Android (carte SD branchée par un adaptateur USB) :

**[Télécharger R36S Studio Android (APK)](https://github.com/nonotrichlozz/r36s-studio/raw/android-apk/R36S-Studio-Android.apk)**

Ce lien donne toujours la dernière version. Une fois installée, l'application se met à jour elle-même à l'ouverture. Version d'essai : son code est dans le dépôt [r36s-studio](https://github.com/nonotrichlozz/r36s-studio/tree/android-app/android-app), pas ici.
